# geometric_lib
Небольшая библиотека на Python для вычисления площади и периметра геометрических фигур: круга, прямоугольника, квадрата и треугольника.
Для каждой фигуры написан отдельный модуль с двумя функциями: `area()` и `perimeter()`.

## Модули

| Модуль | Фигура | Периметр | Площадь |
|:-------|:-------|:---------|:--------|
| `circle.py` | Круг | P = 2πR | S = πR² |
| `rectangle.py` | Прямоугольник | P = (a + b) · 2 | S = a · b |
| `square.py` | Квадрат | P = 4a | S = a² |
| `triangle.py` | Треугольник | P = a + b + c | S = a · h / 2 |

## Использование

В каждом модуле функции называются одинаково (`area` и `perimeter`), поэтому вызывать их нужно через имя модуля:

```python
import circle
import square

print(circle.area(3))  # 28.274333882308138
print(square.area(3))  # 9
```

> [!NOTE]
> Все длины передаются в одних и тех же единицах измерения, результат получается в тех же единицах (для площади — в квадратных).

## Описание функций по файлам

### 1. Круг (circle.py)

| Периметр | Площадь |
|-------|------|
| `perimeter(r)` | `area(r)` |

#### `perimeter(r)`

**Параметры:**

| Параметр | Описание | Тип |
|-------|-----|---|
| `r` | Радиус круга | целое \| дробное число |

Вычисляет периметр окружности по формуле P = 2πR.

**Возвращает:** периметр (длину окружности) круга.

```python
import circle

print(circle.perimeter(5))  # 31.41592653589793
```

#### `area(r)`

**Параметры:**

| Параметр | Описание | Тип |
|-------|-----|---|
| `r` | Радиус круга | целое \| дробное число |

Вычисляет площадь круга по формуле S = πR².

**Возвращает:** площадь круга.

```python
import circle

print(circle.area(3))  # 28.274333882308138
```

### 2. Прямоугольник (rectangle.py)

| Периметр | Площадь |
|-------|------|
| `perimeter(a, b)` | `area(a, b)` |

#### `perimeter(a, b)`

**Параметры:**

| Параметр | Описание | Тип |
|-------|-----|---|
| `a` | Длина первой стороны | целое \| дробное число |
| `b` | Длина второй стороны | целое \| дробное число |

Вычисляет периметр прямоугольника по формуле P = (a + b) · 2.

**Возвращает:** периметр прямоугольника.

```python
import rectangle

print(rectangle.perimeter(4, 5))  # 18
```

#### `area(a, b)`

**Параметры:**

| Параметр | Описание | Тип |
|-------|-----|---|
| `a` | Длина первой стороны | целое \| дробное число |
| `b` | Длина второй стороны | целое \| дробное число |

Вычисляет площадь прямоугольника по формуле S = a · b.

**Возвращает:** площадь прямоугольника.

```python
import rectangle

print(rectangle.area(3, 5))  # 15
```

### 4. Треугольник (triangle.py)

| Периметр | Площадь |
|-------|------|
| `perimeter(a, b, c)` | `area(a, h)` |

#### `perimeter(a, b, c)`

**Параметры:**

| Параметр | Описание | Тип |
|-----|-------|----|
| `a` | Длина основания (для периметра — первой стороны) | целое \| дробное число |
| `b` | Длина второй стороны (только для периметра) | целое \| дробное число |
| `c` | Длина третьей стороны (только для периметра) | целое \| дробное число |

Вычисляет периметр треугольника по формуле P = a + b + c.

**Возвращает:** периметр треугольника.

```python
import triangle

print(triangle.perimeter(4, 5, 6))  # 15
```

#### `area(a, h)`

**Параметры:**

| Параметр | Описание | Тип |
|-----|-------|----|
| `h` | Высота, опущенная на основание (только для площади) | целое \| дробное число |


Вычисляет площадь треугольника по формуле S = a · h / 2.

**Возвращает:** площадь треугольника.

```python
import triangle

print(triangle.area(3, 4))  # 6.0
```
